# GitHub deployment status

The `vercel-supabase-production` branch is the reviewed production replacement.

- Hosting: Vercel
- Persistent state and scheduler: Supabase
- Bot transport: Telegram HTTPS webhook
- Trading mode: paper only
- Separate worker host: none
- Live wallet signing: absent

Provider-owned secrets must be entered only in Vercel and Supabase account controls. They are deliberately not committed to Git.
